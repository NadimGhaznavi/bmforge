**Build small. Fail visibly. Own the implementation.**

BMForge turns engineering decisions into **versioned specifications, proven patterns and project-local AI agent skills**. Codex follows the project owner's software development lifecycle (SDLC).

## From requirements to an independent application

![BMForge architecture: the owner directs an AI agent, pinned component skills guide development, and the repository ships code and skills together to contributors. Application code runs independently; field experience improves specifications.]({{ '/pages/images/bmforge-sdlc.en.svg' | relative_url }})

**Ship the development knowledge with the code.** Pinned skills travel with the source, giving contributors and their agents the project's specifications and standards.

## The engineering philosophy

**One standard, no legacy baggage.** Keep implementations lean, make failures visible and require approval for new technology choices. Refactor older applications deliberately when adopting improved standards.
